# TypeFlow — Typing Speed Tester

TypeFlow is a simple and professional typing speed tester built using HTML, CSS, and JavaScript.

It helps users practice typing and measure their typing speed and accuracy through different difficulty levels.

## Features

- Easy, Medium, and Hard difficulty levels
- 30-second Easy test
- 1-minute Medium test
- 2-minute Hard test
- Random typing passages
- WPM calculation
- Accuracy calculation
- Best WPM tracking
- Correct and incorrect character highlighting
- Current character highlighting
- Word count
- Character count
- Countdown timer
- Progress bar
- Low-time warning
- Performance message
- Restart test
- Dark mode
- Light mode
- Local Storage
- Responsive design
- Professional UI
- Signature watermark

## Difficulty Levels

### Easy

- Time: 30 seconds
- Suitable for beginners
- Short and simple passages

### Medium

- Time: 1 minute
- Moderate-length passages
- Suitable for regular practice

### Hard

- Time: 2 minutes
- Longer and more challenging passages
- Suitable for advanced practice

## How It Works

1. Select a difficulty level.
2. Read the displayed passage.
3. Start typing in the input area.
4. The timer starts automatically when typing begins.
5. Type as accurately as possible.
6. Your WPM and accuracy are updated while typing.
7. The test ends when the timer reaches zero or the complete passage is typed.
8. Your final result is displayed.
