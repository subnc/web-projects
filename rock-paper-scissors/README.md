# Rock Paper Scissors

A simple and professional web-based **Rock Paper Scissors game** built using HTML, CSS, and JavaScript.

The game allows the player to compete against the computer, track scores and rounds, maintain win streaks, and save game statistics using Local Storage.

## Features

- Rock, Paper, and Scissors gameplay
- Computer opponent with random choices
- Automatic winner detection
- Player and computer score tracking
- Round counter
- Games played statistics
- Total wins tracking
- Current win streak
- Best win streak
- Win streak notifications
- Restart current game
- Sound effects using Web Audio API
- Sound On/Off control
- Dark and light themes
- Theme preference saved with Local Storage
- Game statistics saved with Local Storage
- Smooth choice and result animations
- Responsive design
- Professional blue-gray UI
- Personal signature watermark

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
- Web Audio API
