# Countdown Clock ⏳

A simple and professional countdown clock built using HTML, CSS, and JavaScript. Set a custom event, choose a date and time, and track the remaining time with a live countdown.

## 🚀 Live Demo

[View Live Demo](#)

## ✨ Features

- Create a custom countdown event
- Set event name, date, and time
- Live countdown display
- Days, hours, minutes, and seconds
- Pause and resume countdown
- Reset countdown
- Quick countdown presets:
  - 1 Minute
  - 5 Minutes
  - 1 Hour
  - 1 Day
- Progress bar showing countdown progress
- Completion screen when the countdown reaches zero
- Completion sound
- Saves countdown data using Local Storage
- Recovers countdown after page refresh
- Light and dark mode
- Responsive design for mobile and desktop
- Personal Subin C signature watermark

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Web Audio API
- SVG
