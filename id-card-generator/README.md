# ID Card Generator

A simple and professional web-based **ID Card Generator** built using HTML, CSS, and JavaScript.

The application allows users to create a customizable ID card, preview it in real time, generate a QR code, upload a profile photo, and download or print the completed ID card.

## Features

- Live ID card preview
- Enter personal and organization details
- Profile photo upload and removal
- Three card templates:
  - Blue Professional
  - Green Modern
  - Purple Elegant
- Custom card accent color
- Automatic QR code generation
- Input validation
- Download ID card as PNG
- Print ID card
- Local Storage support
- Dark and light UI themes
- Responsive design
- Professional card layout
- Personal signature watermark
- High-quality PNG export

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
- HTML5 File API
- Web APIs
- html2canvas
- QRCode.js
