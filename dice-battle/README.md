# Dice Battle

A professional Dice Battle game built using HTML, CSS, and JavaScript. The player competes against the computer in a five-round dice battle.

The project demonstrates JavaScript game logic, DOM manipulation, animations, Local Storage, Web Audio API, responsive design, and theme management.

## Features

- Player vs Computer dice game
- Five-round match
- Random dice rolls from 1 to 6
- Higher dice value wins the round
- Draw handling
- Live score tracking
- Current win streak
- Best win streak
- Round history
- Final match result
- Winner animation
- CSS-based dice
- Dice rolling animation
- Sound effects
- Sound ON/OFF control
- Dark/Light mode
- Local Storage support
- Persistent game statistics
- Persistent sound preference
- Persistent theme preference
- Result modal
- New Game button
- Play Again option
- Toast notifications
- Keyboard support
- Responsive design
- Personal signature watermark
- Professional blue/slate interface

## Game Rules

The game consists of five rounds.

In every round:

1. The player rolls a dice.
2. The computer rolls a dice.
3. Both values are compared.
4. The player with the higher value wins the round.
5. If both values are equal, the round is a draw.

After five rounds, the player with the higher total number of round wins wins the match.
