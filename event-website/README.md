# NEXORA — Event Website

A modern and responsive event website built using HTML, CSS, and JavaScript.

NEXORA represents:

**Technology • Innovation • Ideas**

The website is designed as a professional event landing page with event information, countdown, speakers, schedule, venue details, FAQ, and a registration system.

## Features

- Modern professional event website
- Responsive design for desktop, tablet, and mobile
- NEXORA event branding
- Event countdown timer
- About section
- Event statistics
- Event highlights
- Speaker section
- Event schedule
- Venue information
- Registration form
- Registration ID generation
- Local Storage registration
- Duplicate registration protection
- Registration confirmation modal
- Toast notifications
- FAQ section
- Dark mode
- Light mode
- Mobile navigation menu
- Smooth responsive layout
- Keyboard support
- Signature watermark
- No external libraries required
