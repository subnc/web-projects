# To-Do List

A professional and responsive To-Do List web application built using HTML, CSS, and JavaScript.

The application allows users to create, manage, search, filter, sort, edit, and complete tasks while automatically saving data in the browser using Local Storage.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Low, Medium, and High priority
- Set due dates
- Overdue task detection
- Due Today indication
- All, Active, and Completed filters
- Dynamic task counts
- Search tasks
- Sort by:
  - Newest
  - Oldest
  - Due Date
  - Priority
- Clear completed tasks
- Custom confirmation modal
- Context-aware empty states
- Task statistics
- Completion progress percentage
- Dark and Light themes
- Theme persistence
- Local Storage persistence
- Toast notifications
- Input validation
- HTML escaping for task content
- Responsive design
- Keyboard support
- Subin C signature watermark

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
- DOM Manipulation
- CSS Animations
