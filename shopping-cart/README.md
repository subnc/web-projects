# 🛒 ShopEasy – Shopping Cart

A simple and responsive **Shopping Cart web application** built using **HTML, CSS, and JavaScript**.

ShopEasy allows users to browse products, search and filter items, add products to the cart, update quantities, apply coupons, and complete a simple checkout process.

## ✨ Features

- 🛍️ Product listing
- 🔍 Search products
- 🗂️ Filter products by category
- ➕ Add products to cart
- ➖ Increase or decrease quantity
- 🗑️ Remove products from cart
- 💰 Automatic subtotal and total calculation
- 🎟️ Coupon code support
- 💳 Checkout form
- ✅ Order confirmation with order ID
- 💾 Cart data saved using Local Storage
- 🌙 Dark mode / Light mode
- 📱 Responsive design for mobile and desktop
- ✍️ Personal signature watermark

## 🎟️ Coupon

Use the following coupon code during checkout:

```text
SAVE10
```

This gives a **10% discount** on the order.

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Cart functionality and interactions
- **Local Storage** – Saving cart data
- **Web APIs** – Theme and checkout interactions
