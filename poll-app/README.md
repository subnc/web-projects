# Poll App

A simple and professional **Poll App** built using HTML, CSS, and JavaScript.

The application allows users to create polls, add multiple options, vote on a poll, and view the results with percentages and statistics.

## Features

- Create a poll
- Add 2 to 6 poll options
- Remove poll options
- Prevent duplicate option names
- Unique Poll ID generation
- Vote for an option
- Prevent repeated voting in the same browser
- Display total votes
- Display vote percentages
- Progress bars for poll results
- Show leading option
- Show highest vote count
- Share poll
- Copy poll link
- Reset all votes
- Delete current poll
- Custom confirmation dialog
- Toast notifications
- Dark mode
- Light mode
- Theme preference saved in Local Storage
- Poll data saved in Local Storage
- Voting status saved in Local Storage
- Responsive design
- Mobile-friendly interface
- Keyboard Escape support
- HTML input escaping for safer display
- Signature watermark
