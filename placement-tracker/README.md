# Placement Tracker

A professional **Placement Tracker web application** built using **HTML, CSS, and JavaScript**. It helps students organize job applications, monitor recruitment progress, track deadlines, and manage placement-related notes in one place.

## Features

- Add new job/placement applications
- Edit existing applications
- View complete application details
- Delete applications with confirmation
- Search applications by company, job role, or location
- Filter applications by status
- Sort applications by:
  - Latest Application
  - Oldest Application
  - Nearest Deadline
  - Company A–Z
  - Company Z–A
  - Status
- Recruitment progress tracking:
  - Wishlist
  - Applied
  - Online Test
  - Interview
  - Selected
- Rejected application status
- Application deadline tracking
- Automatic deadline warnings
- Dashboard statistics:
  - Total Applications
  - Applied
  - Interviews
  - Selection Rate
- Notes / Remarks for each application
- Data persistence using Local Storage
- Dark and Light themes
- Toast notifications
- Required-field validation
- Deadline validation
- Responsive design for desktop, tablet, and mobile
- HTML escaping for safer user-input rendering
- Custom delete confirmation modal
- Modal closing using outside click or Escape key
- Personal **Subin C** signature watermark

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
- DOM Manipulation
- Responsive CSS

No external libraries or frameworks are required.
